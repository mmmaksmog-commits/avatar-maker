# 🎨 Аватар по имени

**Из имени рождается уникальный аватар или логотип: 6 стилей, экспорт в PNG и SVG.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/avatar-maker/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Детерминированная генерация: хеш имени → seed
- Стили: баухаус, пиксели, орбиты, капля, монограмма, волны
- 10 палитр, формы и инициалы
- Экспорт PNG 1024×1024 и SVG
- Аватары для всей команды

## Стек

JavaScript, SVG, Canvas. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/avatar-maker.git
cd avatar-maker
python3 -m http.server 8000
```
